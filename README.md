Project Name: Finance Dashboard – Power BI
Author: Kavya Rai

📌 Project Overview
This project is a Finance Analysis Dashboard created using Power BI.
The dashboard covers key metrics like:
Sales Revenue Analysis
Profit & Loss Statement
Cross-Country Comparison
Gross Profit Margin (GPM) & Net Profit Margin (NPM)
Overall Financial Performance Trends

The purpose of this project is to visualize and analyze financial data for better business decision-making.

📊 Pages Included in Dashboard

Sales Revenue Overview
Profit & Loss Statement (P&L)
Cross Country Analysis
Financial KPIs (GPM, NPM, etc.)

📁 Files in this Repository

Finance_Dashboard.pbix → Power BI File

🚀 How to Use the Dashboard
Download the .pbix file.
Open it in Power BI Desktop.
Make sure the Excel file is in the same folder for refresh.
View dashboards and interact with charts.
